## 2. 郵件文案

### 主旨
「加密 AI」只加密傳輸還不夠：神盾殼 HEShell 的分級與 FAIL-CLOSED 原則

### 預覽文字
L0 不算隱私；端點不支援密文就拒絕；拔掉 USB，畫面與記憶體明文立即清除。

### 內文結構

**① 開場**
傳輸層加密（TLS／HTTPS）下，伺服器端仍是明文，因此 HEShell 不把它當作隱私賣點【事實錨點：《P04》／§4 L0–L3 分級表 L0】。

**② 產品是什麼**
HEShell 是 AEGIS（`aegis.expert`）規劃中的本機 AI 安全殼層；它不訓練模型，也不自行實作密碼學基元，負責的是金鑰邊界、密文路由與本機明文防護【事實錨點：《P04》／§3 第 1 段】。

**③ 能力分級（對外說明必須照此）**
- L1 指定 HE API 固定電路密文運算（Embedding 比對、距離計算、數值評分與分類）：本期交付
- L2 端點密文模型推論：條件交付，只限具備明確能力宣告的端點
- L3 任意閉源商用 LLM 直接處理密文並即時生成：非現行科技，不承諾
【事實錨點：《P04》／§2 可保留內容「L0–L3 能力分級」；§4 分級表】

**④ 四項防護設計**
1. FAIL-CLOSED：沒有「改送明文」的後備路徑；出境封包若含自然語言明文字元，就強制關閉連線（`HE_003`）【事實錨點：《P04》／§4 第 2 點】
2. USB 硬體金鑰：硬體憑證與非對稱挑戰握手；每次對話產生 Session；自 HE Provider 取回一把加密私鑰，私鑰於本機當場組合為複合金鑰（Combined Key）後存放於 USB；HE Provider 不能接觸到這把私鑰；伺服器端不持有解密金鑰；明文不會送到外部的 HE Provider；USB 位於虛擬機的 USB 埠，可自行備份、遺失不補發、不做雲端備份【事實錨點：使用者 2026-11-13 22:20 答覆；HEShell #8 草稿《P04》§4 第 3 點、TM-01（PR 尚未合併）】
3. 本機記憶體防護：以 `mlock`／`VirtualLock` 防止明文寫入 Swap/Pagefile【事實錨點：《P04》／§4 第 5 點】
4. 零明文日誌：封鎖 Full Memory Dump【事實錨點：《P04》／§4 第 6 點】

**⑤ 範圍說明**
一般雲端 AI 聊天 API 不能直接處理密文（L3），HEShell 會拒絕這類路由【事實錨點：《P04》／§7 FAQ 第 1 題】。價格、硬體規格與上線時程目前尚未公布【事實錨點：《P04》／§7 FAQ 最後一題】。

「密文運算比明文慢得多，這是目前技術的事實。HEShell 不會用逐字跳出的動畫假裝即時，而是清楚顯示每個階段：金鑰封裝、密文傳輸、同態運算、接收結果（原為密文下載、本機解密；因結果以明文回傳而調整，階段名稱是否再調整 [待確認]）。你知道系統在做什麼，也知道為什麼要等。」【事實錨點：使用者 2026-11-13 22:20 答覆；HEShell #8 草稿《P04》§2「介面規範」、§7 短文案（誠實說明速度）（PR 尚未合併）】

### 版本 D｜FAQ 問答版（適用情境：業務問答）
- **Q：可以用 HEShell 加密我們現在用的雲端 AI 聊天服務嗎？** A：不行。一般商用 LLM API 不能直接處理密文（L3 不是現行技術）；HEShell 只會把請求送往有明確密文能力宣告的端點【事實錨點：《P04》／§7 FAQ 第 1 題】。
- **Q：v1 能做什麼？** A：L1：指定 HE API 上的固定電路密文運算，例如 Embedding 比對、距離計算、數值評分與分類；L2 為條件交付，取決於端點能力【事實錨點：《P04》／§7 FAQ 第 2 題】。
- **Q：HEShell 會用我們的資料訓練模型嗎？** A：不會。HEShell 不訓練、不微調模型【事實錨點：《P04》／§7 FAQ 第 4 題】。
- **Q：多少錢、何時可以用？** A：價格、硬體規格與上線時程目前尚未公布【事實錨點：《P04》／§7 FAQ 第 6 題】。
- **Q：明文會送到外部 HE Provider 嗎？金鑰如何保存？** A：明文不會送到外部的 HE Provider。私鑰於本機當場組合為複合金鑰後存放於 USB，HE Provider 不能接觸到這把私鑰；伺服器端不持有解密金鑰。結果以明文回傳。【事實錨點：使用者 2026-11-13 22:20 答覆；HEShell #8 草稿《P04》§7、TM-01（PR 尚未合併）】
- **Q：回傳的結果也是加密的嗎？** A：不是。HEShell 的結果以明文回傳；加密範圍為送出的使用者輸入。【事實錨點：HEShell #8 草稿《P04》§7 FAQ「回傳的結果也是加密的嗎？」（PR 尚未合併）】
- **Q：USB 遺失怎麼辦？** A：可以自行備份 USB，但遺失不補發。不做雲端備份（對外傳輸的是複合金鑰的組件，不是提問文字）。USB 位於虛擬機的 USB 埠。【事實錨點：使用者 2026-11-13 22:20 答覆；HEShell #8 草稿《P04》§7 FAQ「USB 遺失怎麼辦？」（PR 尚未合併）】
